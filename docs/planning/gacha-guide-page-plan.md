# ガチャ機能の紹介ページ（/guide/gacha）計画書

- 作成日: 2026-10-05
- 状態: 計画（レビュー待ち）
- 見本: https://claude.ai/artifact/W7ogB21qLFw159df2NEU2W （ユーザーと合意した構成・文言）
- 関連: `docs/planning/` のガチャプロンプト計画（#675）、`features/generation/components/GachaPromptField.tsx`

## 1. 目的

ガチャプロンプトのやり方がわからない人が多い。初めてペルスタに来た人でも、

1. ガチャ機能で何ができるか
2. どの画面から使えるか
3. どう作るか

を、文字を読み込まなくても絵と実際の画面で分かるページを作る。

## 2. 決まっていること（2026-10-05 ユーザー決定）

| 項目 | 決定 |
|---|---|
| URL | `/guide/gacha` |
| 公開 | ガチャ機能と同じく、**運営だけに見せる**（`isGachaPromptAvailable(user.id)` が false の人には 404） |
| 言語 | **文字はすべて15言語に対応**する。**画像（画面のスクショ・生成画像）は日本語版1種類**で全言語共通 |
| 入口 | ホームのカード・バナーなどの入口は、ページができてから別に相談する（この計画には含めない） |
| 見た目 | 章ごとに画面の端から端まで色を敷く。白い枠で囲まない。横幅を狭く制限しない（パソコンでは横に並べる） |
| アニメーション | 実装してから、本番に近い画面で試して決める |

## 3. ページの構成（上から順に）

見本と同じ。文言は見本のものを日本語の正本とする。

| 章 | 背景 | 中身 |
|---|---|---|
| ① 新機能 | ピンク→オレンジ | 「NEW」／見出し「ガチャプロンプトのかたよりをなくす機能を追加！」／問いかけ1文／「これまで（AIに選ばせる）」「これから（ガチャ機能）」の比べた図／説明1文 |
| ② ガチャでできること | 水色 | お仕事体験ガチャ／今日のコーデガチャ／みんなに使ってもらう（各3枚＋1文） |
| ③ どこから使える？ | 黄色 | 実際の画面3枚（ホーム → Perstaのカタログ → カタログをつくる）に枠と吹き出し／パソコンの場合・ログインが必要なことの補足 |
| ④ 6ステップで、ガチャをつくろう | ミント | 1 画像を選ぶ／2 ガチャ用のプロンプトを書く／3 チェック／4 ガチャの欄に番号と中身を書く／5 サポート機能（便利・3枚の流れ）／6 生成する／★ 毎回ちがう結果 |
| ⑤ 締め | 紺 | 「さっそく、ガチャを作ってみよう」／「ガチャをやってみる」ボタン（`/free` へ） |

## 4. 作り方

### 4.1 ファイル

| ファイル | 内容 |
|---|---|
| `app/guide/gacha/page.tsx` | ページ。ログインしている人を見て、運営でなければ `notFound()`。`metadata` は `robots: { index: false }`（運営だけの間は検索に出さない） |
| `features/guide/components/GachaGuide.tsx` | ページの中身（章ごとに小さい部品へ分ける） |
| `features/guide/components/AnnotatedShot.tsx` | 画面のスクショに、枠と吹き出しを重ねる部品。位置は画像に対する割合（%）で持つ |
| `public/guide/gacha/*.jpg` | 画像（日本語版のみ）。幅780pxのJPEG、合計およそ1MB |
| `messages/*.ts`（15言語） | 新しい名前空間 `gachaGuide` に、ページの文字をすべて入れる |

### 4.2 文字と画像を分ける（言語対応の要）

- **吹き出し・見出し・説明文は、画像に焼き込まず HTML の文字で重ねる。** 画像は1種類のまま、吹き出しの文字だけ各言語に切り替わる。
- 吹き出しの中の画面の名前（「カタログ」「CREATE」「ガチャプロンプトにする」「本文からガチャを作る」「採用する」「コーデ開始！」など）は、**各言語の実際の画面の文言を `messages` から参照する**（ページ専用に書き写さない）。画面の文言が変わったとき、案内が古くならないようにするため。
- 画像の `alt` も各言語に訳す。
- 画像の中の文字は日本語のままなので、ほかの言語の人には「画面の位置を示す絵」として見せる。吹き出しの文字で、どこを押すか分かるようにする。

### 4.3 画像

- 画面のスクショは、手元で Persta を起動し iPhone 13 の大きさで撮る（見本で使ったものと同じ手順）。
  - ログインした見た目は、撮影用の作業場所だけで一時的に書き換えて撮る。コードには残さない。
  - 「ガチャに分ける」は、AIの返事を作り置きに差し替えて撮る（AIを呼ばない・ペルコインを使わない）。
- 撮り直したときに枠の位置がずれないよう、撮影の手順を `scripts/` に残すかは実装時に判断する（残す場合も本番のビルドには含めない）。
- 「できること」と「これまで／これから」の生成画像は、実際にガチャで出た画像を使う（見本と同じ）。差し替える場合は運営が選ぶ。

### 4.4 画面の幅

- スマホ: 縦に1列。左右に16pxの余白。
- パソコン（860px以上）: できることは3列、使い方は2列、サポート機能の3枚は横並び。内容の最大幅は1200px（章の背景は端まで）。

## 5. 公開の手順

1. 実装をマージ（運営だけに見える）
2. 本番で、運営アカウントでスマホとパソコンの見え方を確かめる
3. アニメーションを試して決める
4. ガチャ機能を一般公開するときに、このページも一緒に公開する
   - `notFound()` の条件をガチャ機能の公開フラグに合わせる（同じ `isGachaPromptAvailable` を使うので、フラグを立てれば自動で公開になる）
   - 公開のときに、`robots` の `index: false` を外すか、サイトマップに入れるかを決める
   - 言語ごとの URL（`/en/guide/gacha` など）にするかも、このとき決める（運営だけの間は、言語は今の設定に従って切り替える）
5. 入口（ホームのカードなど）を別に相談して作る

## 6. テスト

- 運営でない人・ログインしていない人は 404 になる
- 運営は表示できる
- 15言語すべてに `gachaGuide` の文言がそろっている（足りないキーが無い）
- 吹き出しに出す画面の名前が、生成画面と同じ文言を参照している
- 「ガチャをやってみる」が `/free` へのリンクになっている

## 7. やらないこと

- 入口（ホームのカード・バナー）
- 画像の言語別の作成
- アニメーションの作り込み（実装後に別途）
- ガチャの欄の赤字（チェック直後に「候補を2つ以上入れてください」が出る件）の修正。気づいた点としてユーザーに判断を依頼済み。直す場合は別の PR
